# Bash Scripting

A collection of Bash scripting solutions for common programming problems and exercises. This repository is mainly focused on learning and practicing Bash scripting through hands-on problem solving.

## About

This repository contains:

* Bash scripts for common programming problems
* Solutions to practice exercises
* Beginner to intermediate Bash scripting concepts
* Examples of loops, conditions, string handling, arithmetic, file operations, and command-line utilities

The scripts are written while practicing from different coding and learning platforms.

## Running the Scripts

Clone the repository:

```bash
git clone <repo-url>
cd bash-scripting
```

Make a script executable:

```bash
chmod +x script.sh
```

Run the script:

```bash
./script.sh
```

Or:

```bash
bash script.sh
```
